### Ready for Patchy 1.5.0

Patchy 1.5.0 adds tab completion for people who use Patchy in Terminal. Nothing changes in Patchy UI, which now expects Patchy 1.5.0 so it won't warn you about a version mismatch.

Made for **Patchy 1.5.0**. Update Patchy first, in Terminal: `brew upgrade joeworkman/patchy/patchy`
