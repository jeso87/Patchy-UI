### Finish Patchy's setup from the app

Patchy 1.4.1 won't add a site until its one-time setup has run on your Mac. If Patchy UI finds setup hasn't finished when you add a site, it says so and offers **Finish Setup**. That runs the setup, asking for your Mac password if it needs it, and then adds your site.

Made for **Patchy 1.4.1**. Update Patchy first, in Terminal: `brew upgrade joeworkman/patchy/patchy`
