### The first release of Patchy UI

Patchy UI puts a window and a menu bar item on top of Patchy, so you can host
websites on your Mac without opening Terminal.

- See every site and its health at a glance
- Add a site, remove it, or point it at a different folder
- Group related sites, such as one customer's domain and subdomains
- Start, stop and restart the server
- Follow each site's error and visit logs live
- Switch PHP version and refresh certificates
- Set up password-free mode once, with your Mac password

This version is made for **Patchy 1.2.1**. Patchy UI's version number always
matches the Patchy release it supports.
