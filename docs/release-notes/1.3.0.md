### New

- **Share a site at a public link,** so a client can see a preview. Click Share on a site: you get a link that works until you stop sharing. If you've connected your own domain with `patchy share setup`, Share asks each time: your site's own address on that domain, with or without a password, or a temporary address that is new each time. With a password, **Copy Address and Password** puts everything your client needs on the clipboard.
- **A new menu bar panel.** Type part of a site's name and press Return to open it in your browser; the arrow keys move through the list. Sites with a problem are listed first, then your groups.
- **A keyboard shortcut for the panel,** set in Settings › General. It works from any app, so you can open a site without touching the mouse.

### Changes

- Patchy UI now asks Patchy for everything through its new machine-readable output, instead of reading Patchy's files. Future Patchy releases can change how they store things without breaking the app.
- Changing a site's folder now uses Patchy's own `patchy folder` command.
- While a change runs, the app now shows one step instead of a checklist, because Patchy now reports only the result.

Made for **Patchy 1.3.0**. Update Patchy first, in Terminal: `brew upgrade joeworkman/patchy/patchy`
