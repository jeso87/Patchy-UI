### New

- **Start a Total CMS 3 site.** New Site has an **Install Total CMS 3** checkbox. Tick it, choose an empty folder, and Patchy UI installs Total CMS 3 there with Composer, then adds the site so it opens at the setup wizard. You can pick the layout, a starter, the frontend tools and whether templates are kept in Git. If Composer isn't on your Mac, Patchy UI installs it with Homebrew first. The checkbox can be hidden in Settings › General.
- **Update Total CMS / Update Packages.** A site that uses Composer gets an update button that runs `composer update`, so Total CMS and its plugins (or any other packages) stay current. Composer always runs with the PHP your server uses.

Still made for **Patchy 1.5.0**.
