### Ready for Patchy 1.5.1

Patchy 1.5.1 fixes first-time setup on a Mac that has never run Patchy before: setup used to fail with an Apache error, so new users couldn't add a site. Nothing changes in Patchy UI, which now expects Patchy 1.5.1 so it won't warn you about a version mismatch.

Made for **Patchy 1.5.1**. Update Patchy first, in Terminal: `brew upgrade joeworkman/patchy/patchy`
